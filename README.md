# Кофейня на двоих — прототип MVP

Асинхронный кооп на двоих для Telegram Mini App: вместе ведёте кофейню, на выручку обустраиваете квартиру над ней и заводите кота. Концепт: «Наше место» (документ в проекте Telegram Games).

**Играть в браузере:** https://grigory2508.github.io/coffee-for-two/

> Один раз нужно включить Pages: Settings → Pages → Source: **Deploy from a branch** → ветка **gh-pages**, папка **/(root)**. Сборку в эту ветку выкладывает workflow при каждом пуше в `main`.

## Что есть в прототипе

- **Кофейня (Акт 1).** Смена — мини-игра на 75 секунд: 5 гостей, собираешь напиток из ингредиентов и подаёшь. Порядок ингредиентов не важен, у гостей кончается терпение. За смену тратится 1 единица сил; всего их 3, одна восстанавливается за 4 часа.
- **Склад и управление.** Закупки с лимитом вместимости, 3 новых напитка в меню, 3 улучшения. У управляющего растёт скидка.
- **Постоянные гости.** У троих гостей истории по 5 визитов. Каждую сцену видит только тот, кто стоял за стойкой; напарник видит «это слышал(а) Аня — спроси».
- **Ворота 1 → квартира над кофейней.** Нужны рейтинг 3★ и 8 смен. В квартире 24 предмета декора в 8 местах и кот: его надо кормить и гладить, кот в хорошем настроении приходит в кофейню и даёт +10% чаевых.
- **Двое и NPC.** Пока напарника нет, сосед Артур раз в 6 часов выходит на смену вполсилы. По ссылке-приглашению напарник занимает его место. Третьему вход закрыт.
- **Связь между напарниками.** Доска записок со стикерами, сводка «Пока тебя не было», журнал событий. Кнопки «Попросить напарника» отправляют карточку в вашу переписку.
- **Рейтинг кофеен недели.** Очки за довольных гостей; если оба напарника работали в этот день — ×1.2. Соседи по рейтингу пока сгенерированные.
- **RU и EN.** Язык берётся из Telegram, переключается в отладке.
- **Отладка (🛠).** Промотка времени на +1ч/+4ч/+1д/+1нед (только в локальном режиме), «силы и +1000 🪙», вкладка напарника, сброс.

## Как поиграть вдвоём без сервера

Локальный режим хранит кофейню в `localStorage` браузера. Поэтому «двое» в нём — это две вкладки одного браузера:

1. Откройте игру и откройте кофейню.
2. 🛠 → «Открыть вкладку напарника» — откроется вторая вкладка со ссылкой-приглашением от другого игрока.
3. Играйте по очереди: всё, что делает один, сразу видно другому.

Чтобы играть с двух телефонов, нужен сервер (ниже).

## Устройство

```
src/core/        логика игры: чистые функции, общие для клиента и сервера
  content.ts     весь контент и баланс (напитки, цены, декор, гости, CONFIG)
  engine.ts      команды (apply), время (advance), смена, NPC, ворота, сводка
src/net/         Backend: LocalBackend (localStorage + BroadcastChannel) и RemoteBackend (API)
src/platform/    Telegram WebApp, часы с промоткой, личность игрока, аналитика PostHog
src/ui/          интерфейс на Preact, SVG-заглушки вместо арта
supabase/        сервер: SQL-схема, функции api (команды) и bot (вебхук + сводки)
scripts/         sync-server (копия ядра на сервер), e2e (прогон двух игроков в Playwright)
```

Состояние кофейни — один JSON. Клиент и сервер применяют одни и те же команды из `src/core/engine.ts`. Сервер хранит строку на кофейню и защищает её от одновременной записи двух напарников через версию.

Баланс собран в `src/core/content.ts` (`CONFIG`, цены, рецепты) — менять цифры там.

## Команды

```bash
npm install
npm run dev          # локально на http://localhost:5173
npm test             # тесты ядра (vitest)
npm run build        # сборка в dist/
npm run sync-server  # скопировать src/core в supabase/functions/_shared/core (после правок ядра!)
node scripts/e2e.mjs # прогон двух игроков (нужен playwright и запущенный `npx vite preview --port 4173`)
```

Каждый пуш в `main` прогоняет тесты, проверяет, что ядро на сервере совпадает с клиентским, и выкладывает сборку на GitHub Pages.

## Подключение бота и сервера

### 1. Бот и Mini App (BotFather)

1. `/newbot` — создайте бота и сохраните токен.
2. `/newapp` — Mini App с URL `https://grigory2508.github.io/coffee-for-two/` и коротким именем, например `play`.
3. `/setinline` — включите инлайн-режим (приглашение через `@бот` в любом чате), плейсхолдер: «позвать в кофейню».
4. `/setmenubutton` — кнопка меню на тот же URL.

### 2. Supabase

1. Создайте проект. Выполните `supabase/migrations/0001_init.sql` в SQL Editor.
2. Задайте секреты функций (Dashboard → Edge Functions → Secrets или `supabase secrets set`):
   - `BOT_TOKEN` — токен бота;
   - `BOT_USERNAME` — имя бота без @;
   - `APP_SHORTNAME` — короткое имя Mini App (`play`);
   - `WEBHOOK_SECRET` — любая случайная строка;
   - `CRON_SECRET` — другая случайная строка;
   - `ALLOW_DEBUG=1` — только на время теста (разрешает «силы и +1000»).
3. Задеплойте функции:
   ```bash
   npm run sync-server
   supabase functions deploy api --no-verify-jwt
   supabase functions deploy bot --no-verify-jwt
   ```
4. Повесьте вебхук бота:
   ```
   https://api.telegram.org/bot<TOKEN>/setWebhook?url=https://<project-ref>.functions.supabase.co/bot&secret_token=<WEBHOOK_SECRET>&allowed_updates=["message","inline_query","pre_checkout_query","my_chat_member"]
   ```
5. Сводки раз в час: включите расширения `pg_cron` и `pg_net` и выполните `cron.schedule` из конца файла миграции.

### 3. Сборка на GitHub

Settings → Secrets and variables → Actions → **Variables**:

| Переменная | Значение |
| --- | --- |
| `BOT_USERNAME` | имя бота без @ |
| `APP_SHORTNAME` | `play` |
| `API_URL` | `https://<project-ref>.functions.supabase.co/api` |
| `POSTHOG_KEY` | ключ проекта PostHog (необязательно) |
| `DEBUG` | `0`, чтобы скрыть отладку (по умолчанию включена) |

После сохранения перезапустите workflow «Deploy to GitHub Pages». Без `API_URL` игра работает в локальном режиме и в Telegram: соло с NPC, без синхронизации между устройствами.
